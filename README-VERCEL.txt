ESTACIONAMENTO JR - VERSAO SEM API

Esta versao funciona somente no navegador, sem API, PostgreSQL, Supabase ou backend.

ARQUIVO PRINCIPAL:
- index.html

COMO SUBIR NA VERCEL:
1. Crie um projeto na Vercel.
2. Envie este arquivo/pasta.
3. Nao e necessario configurar banco de dados nem variaveis de ambiente.

DADOS:
- Os cadastros sao salvos no localStorage do navegador.
- Fechar a aba ou atualizar com F5 nao apaga os cadastros naquele mesmo navegador/dispositivo.
- A sincronizacao automatica entre aparelhos diferentes nao existe nesta versao, pois foi removida a API/banco.
- O evento de armazenamento permite atualizar outras abas do mesmo navegador quando os dados mudam.

LOGIN ADMIN:
- Usuario: admin
- Senha: admin

IMPORTANTE:
Se o site for aberto em outro celular/computador, ele tera seu proprio armazenamento local. Para compartilhar os mesmos cadastros entre aparelhos seria necessario algum backend/banco de dados.
